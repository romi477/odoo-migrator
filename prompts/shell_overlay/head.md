# Working inside the Odoo shell

What the tools on the other side of `exec` can do, and the idioms that do it
in one call instead of ten.

This is odoo-sheller's own guidance for an agent, as its daemon serves it
today, with the tool names this app gives you. The parts about opening,
closing, owning and committing sessions are left out: the runner does all of
that, and you never see it.
