Typography

Interface labels are set in the sans stack. Anything that is an identifier, a version, a path or command output is monospaced: 17.0 → 18.0, ir.module.module, odoo18_new.

A migration's colour is a custom property, never a status hue. Status stays green / red / amber / cyan.
