Guide

The steps under the open migration, in the same order as the menu.

  1. Tree

    The modules of this migration, and which ones depend on which. Colour is the step. A later step waits until the earlier ones are done or skipped.

    • Resolve reads the modules from the old Odoo and sorts them into steps.
    • Step buttons under the graph select a whole wave.
    • Leave out / Include again on the dashed node card. Multi-select leave out also hits downstream; include walks depends upward. A lone leaf leaving out walks upward and keeps a shared parent if a sibling branch is still in.
    • Group marks a set of modules to run together. Ungroup takes them back out.
    • Migrate starts the one module you selected.
    • Batch starts the group, in dependency order.

  2. Pipeline

    The module that is moving now: name, status, stage, attempt. When nothing is running, the screen says so. When a batch finishes, the review is here.

    • Continue starts the next work, once every stall has been read.
    • Override continues even if something is still unread.
    • Dismiss marks one failed or waiting module as read.
    • Promote saves a finding into a version's rules. You pick the version file.

  3. n8n

    The workflow that rewrites the module. The drawing stays in n8n. This screen only opens it.

    • Open in n8n goes to the address in settings. If that address is empty, set it with the gear.

  4. Sheller

    The Odoo shell, to watch. The screen is only Sheller's /web iframe edge to edge. The frame cannot write. Pick the live session inside Sheller's own UI. The address comes from settings.

    • The frame is Sheller's own page, without a write key.

  5. Result

    The scoreboard for this migration: the same progress summary as on Overview, then one column per dependency wave with a card per module.

    • Columns are L0, L1, … — the same waves as on Tree.
    • Each card shows status, dependencies, and flags for assumptions or a human wait.
    • Skipped modules stay in their wave, struck through, badge excluded.
    • Progress counts only modules still in the plan.
