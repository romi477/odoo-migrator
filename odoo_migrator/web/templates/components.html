Each module of the batch is one row, the shape of a queue row and a little slimmer, in a column narrower than the cards above it: the name, how it ended, its last attempt and the model on one line, the buttons at its end. A diagnosis, a question or a finding opens under the line. Continue stays off while a failed or waiting job is unread. Override is the explicit skip. Promote asks which version file; the app does not pick one. Dismiss only marks the run as read. A run of a queued module is answered on its queue card, Continue and Discard; this block then holds neither. A run with no card, from Tree, keeps Continue above and Discard run on its card, orange: it deletes the run and asks first; it is off, with the reason on hover, when the module's directory is not a git checkout. The run is said in words, the verdict and the diagnosis: no diff, no raw test output.

The runner as a black box: the module in its old version goes in at the left, the ported one comes out at the right, and a pair of meshed gears turns between them. Idle, waiting for a person, done and failed rest; only a run turns the gears, and the belts carry dashes toward the output. Top to bottom: idle, running, waiting for you (amber gears, still), done (cyan gears, the module at the output), failed (red gears, the module still at the input). Under them, running through a failure: the gears turn and red sparks leave the mesh until the lap is mended. The input slot is amber and the output slot cyan in every state; the gears carry the state.
