# 16.0

What this version still is. A port that lands later leaves these
spellings behind; a module written for 16.0 still uses them. Python
3.7 or newer (`python_requires` in this release). Do not require 3.10
syntax (`match`, `list[int]` as a runtime hint without `from __future__
import annotations`) unless the target file says so.

## Views

The list root tag is `tree`. The view type on `ir.ui.view` is `tree`.
An action's `view_mode` is `tree,form` (that is the default). The
schema is `tree_view.rng` and its element is `tree`. `<list>` is not a
valid root on 16.0, and `view_mode` does not contain `list`. An xpath
that addresses the list is `//tree`.

The server maps the word `tree` to `list` only when it talks to the
web client. That alias is not permission to write `<list>` in XML.

Modifiers are `attrs` and `states`. `invisible`, `readonly` and
`required` are not yet Python expressions:

```xml
<field name="name" attrs="{'invisible': [('state', '=', 'cancel')], 'readonly': [('state', '!=', 'draft')]}"/>
<field name="state" widget="statusbar" statusbar_visible="draft,done"/>
```

`states` on a field is a list of states in which the field is visible
and editable. On a tree column, `invisible` hides the column: the
server stores that as `column_invisible` in the modifiers. Do not
write the attribute `column_invisible` yourself on 16.0.

A kanban card template is `t-name="kanban-box"`. `t-name="card"` is
not this version's name.

## ORM

- `group_operator` is the field attribute for aggregation.
  `aggregator` is not this version's name.
- `_sql_constraints` is a list of `(name, sql, message)` tuples.
- `name_get` is still the method. `display_name` exists and is
  computed from it. Keep a `name_get` override until the target file
  says the method is gone.
- `read_group` is the grouping API. `check_access_rights` and
  `check_access_rule` are the access checks.
- `res.users` membership is `groups_id`. `res.groups` membership is
  `users`. Groups still use `category_id`.

## HTTP

A JSON controller route is `type="json"`. `jsonrpc` is not a route
type on 16.0.
